<section class="ds-section" aria-labelledby="install">
<h2 id="install">Install in one line</h2>
<p class="ds-lead">A single static binary. The only thing it needs is <code>git</code>.</p>

<Tabs syncKey="install">
<TabItem label="Install script" icon="seti:shell">
```sh
curl -fsSL https://raw.githubusercontent.com/pungoyal/dotsync/main/install.sh | sh
```
The script checks the checksum and, if the GitHub CLI is installed, the [signed build provenance](/dotsync/project/verifying-releases/) before it installs anything.
</TabItem>
<TabItem label="Go" icon="seti:go">
```sh
go install github.com/pungoyal/dotsync/cmd/dotsync@latest
```
</TabItem>
<TabItem label="Binary" icon="download">
Download an archive for macOS or Linux (amd64 or arm64) from the [releases page](https://github.com/pungoyal/dotsync/releases/latest), then put `dotsync` on your `PATH`.
</TabItem>
</Tabs>

```sh title="Then, on every machine"
dotsync init git@github.com:you/dotfiles.git
dotsync add ~/.gitconfig ~/.config/fish ~/.config/nvim   # once, from any machine
dotsync doctor                                           # check everything is healthy
```

Upgrade any time with `dotsync update`. It checks the same checksum and provenance.
</section>

<section class="ds-section" aria-labelledby="why">
<h2 id="why">Set it up once. Then forget about it.</h2>
<p class="ds-lead">Most dotfile managers are deployment tools. dotsync is a synchronizer: edit the real file wherever you are, and it shows up everywhere else.</p>

<CardGrid>
	<Card title="Automatic, both ways" icon="random">
		Edit `~/.gitconfig` on your laptop and your desktop has it a few minutes later. Adding and removing managed files works from any machine too.
	</Card>
	<Card title="Never loses your work" icon="approve-check">
		Every file is backed up before it's replaced. If two machines change the same file, both versions are kept and you choose.
	</Card>
	<Card title="Secrets stay home" icon="warning">
		SSH keys, cloud credentials and tokens in your shell config are held back before they ever reach the remote.
	</Card>
	<Card title="Offline is fine" icon="laptop">
		A machine that was away for a month catches up correctly, including noticing conflicts, when it reconnects.
	</Card>
	<Card title="Nothing new to host" icon="github">
		Your dotfiles live in a private git repository you already know how to host. There's no server, account or daemon.
	</Card>
	<Card title="Portable by design" icon="puzzle">
		`~/…` and `$XDG_CONFIG_HOME/…` targets, per-OS entries and per-machine exclusions keep the shared manifest free of machine-specific paths.
	</Card>
</CardGrid>
</section>

<section class="ds-section" aria-labelledby="decides">
<h2 id="decides">One simple rule, applied to every file</h2>
<p class="ds-lead">Each machine remembers the version it last agreed on with everyone else, so dotsync always knows who changed what.</p>

<div class="ds-matrix">
	<div>
		<p class="ds-when">Changed only on another machine</p>
		<p class="ds-then"><span class="ds-dot" style="background: var(--ds-in)"></span>Installed here</p>
		<p class="ds-why">after backing up this machine's copy</p>
	</div>
	<div>
		<p class="ds-when">Changed only on this machine</p>
		<p class="ds-then"><span class="ds-dot" style="background: var(--ds-out)"></span>Sent everywhere</p>
		<p class="ds-why">pushed to the shared repository</p>
	</div>

<section class="ds-section" aria-labelledby="status">
<h2 id="status">Always know where you stand</h2>
<p class="ds-lead"><code>dotsync status</code> shows every managed file, its state on this machine, and anything that needs your attention.</p>

```console frame="terminal" title="dotsync status"
dotsync on laptop: git@github.com:you/dotfiles.git (main @ 1c049fe)
last sync: 2026-09-21T11:16:09+05:30 (ok)
automatic sync: launchd agent loaded

SOURCE            TARGET                      STATUS      DESCRIPTION
fish/config.fish  ~/.config/fish/config.fish  ok          Fish shell configuration
gitconfig         ~/.gitconfig                CONFLICT    Git identity and aliases
nvim              ~/.config/nvim/             1 incoming  Neovim

conflicts (neither version has been changed):
  ~/.gitconfig  since 2026-09-21T11:16:09+05:30
  inspect: dotsync diff <path>    settle: dotsync resolve <path> --keep local|remote
```
