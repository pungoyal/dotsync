dotsync is a single static binary for **macOS and Linux** on **amd64 and arm64**. At runtime it needs `git` 2.20 or newer, and nothing else.

## Install

<Tabs syncKey="install">
<TabItem label="Install script (recommended)">

```sh
curl -fsSL https://raw.githubusercontent.com/pungoyal/dotsync/main/install.sh | sh
```

The script:

1. finds the latest release, and the archive for your OS and CPU
2. checks the archive's **SHA-256 checksum** against the release's `checksums.txt`
3. checks its **signed build provenance** with `gh attestation verify`, if the [GitHub CLI](https://cli.github.com) is installed and logged in
4. installs `dotsync` to `~/.local/bin`
5. re-installs the background agent, if this machine already has one, so it matches the new version

It needs `curl` or `wget`, and `sha256sum` or `shasum`. These variables change what it does:

| Variable | Default | Effect |
|---|---|---|
| `DOTSYNC_VERSION` | latest | release to install, e.g. `v0.5.0` |
| `DOTSYNC_BIN_DIR` | `~/.local/bin` | where to install |
| `DOTSYNC_REQUIRE_ATTESTATION` | `0` | `1` refuses to install unless the provenance check passes |

```sh title="For example"
curl -fsSL https://raw.githubusercontent.com/pungoyal/dotsync/main/install.sh | DOTSYNC_REQUIRE_ATTESTATION=1 sh
```

</TabItem>
<TabItem label="go install">

With Go 1.23 or newer:

```sh
go install github.com/pungoyal/dotsync/cmd/dotsync@latest
```

The binary goes to `$(go env GOBIN)`, or to `$(go env GOPATH)/bin` (usually `~/go/bin`) if `GOBIN` isn't set.

</TabItem>
<TabItem label="Release archive">

1. Download `dotsync_<version>_<os>_<arch>.tar.gz` from the [latest release](https://github.com/pungoyal/dotsync/releases/latest). `<os>` is `darwin` or `linux`; `<arch>` is `amd64` or `arm64`.
2. Optionally, [verify it](/dotsync/project/verifying-releases/).
3. Extract the binary and put it on your `PATH`:

   ```sh
   tar -xzf dotsync_*_darwin_arm64.tar.gz dotsync
   install -m 0755 dotsync ~/.local/bin/
   ```

</TabItem>
<TabItem label="From source">

With Go 1.23 or newer:

```sh
git clone https://github.com/pungoyal/dotsync
cd dotsync
make build        # writes bin/dotsync
```

</TabItem>
</Tabs>

## Put it on your `PATH`

If `dotsync version` says *command not found*, add `~/.local/bin` to your `PATH`:

<Tabs syncKey="shell">
<TabItem label="zsh">
```sh
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && exec zsh
```
</TabItem>
<TabItem label="bash">
```sh
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc && exec bash
```
</TabItem>
<TabItem label="fish">
```fish
fish_add_path ~/.local/bin
```
</TabItem>
</Tabs>

## Check it works

<Terminal code={version} />

That's the version, the commit it was built from and that commit's date, the Go version, and the platform.

<Aside type="tip">
However you install it, `dotsync init` copies the binary to `~/.local/bin/dotsync`. That copy is the one the background agent runs, so a `dotsync` elsewhere on your `PATH` is fine.
</Aside>

## Update

```sh
dotsync update           # install the latest release: checksum and provenance verified
dotsync update --check   # only say whether there's a newer one
```

`update` replaces the binary you ran and, if it's a different file, the agent's copy in `~/.local/bin`. If a background agent is installed, it then re-installs it with the new version, so there's nothing else to do. It only replaces a binary after the checksum matches. [`dotsync doctor`](/dotsync/reference/commands/#doctor) also tells you when an update is available.

Versions before 0.3.0 don't have `update`: run the install script once more to get it. To go back to an earlier release, `dotsync update --version v0.4.0`.

## If the download stalls

With `curl`, the install script shows a progress bar, abandons a transfer that stays below 1 KB/s for 20 seconds, retries, and finally tries once more over IPv4. If it still fails, test your connection to GitHub's download host, which is separate from `github.com`:

```sh
curl -v -o /dev/null https://github.com/pungoyal/dotsync/releases/latest/download/checksums.txt
```

If that hangs too (often a broken IPv6 route, or a proxy), try it again with `curl -4`, or download the archive from the [releases page](https://github.com/pungoyal/dotsync/releases/latest) in a browser.
