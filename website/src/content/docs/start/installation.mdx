dotsync is a single static binary for **macOS and Linux** on **amd64 and arm64**. It needs `git` 2.20 or newer at runtime, and nothing else.

## Install

<Tabs syncKey="install">
<TabItem label="Install script (recommended)">

```sh
curl -fsSL https://raw.githubusercontent.com/pungoyal/dotsync/main/install.sh | sh
```

The script:

1. picks the right archive for your OS and CPU from the latest release
2. checks its **SHA-256 checksum** against the release's `checksums.txt`
3. checks the **signed build provenance** with `gh attestation verify`, if the [GitHub CLI](https://cli.github.com) is installed
4. installs `dotsync` to `~/.local/bin`

| Variable | Default | Purpose |
|---|---|---|
| `DOTSYNC_VERSION` | latest | install a specific release, e.g. `v0.1.0` |
| `DOTSYNC_BIN_DIR` | `~/.local/bin` | install location |
| `DOTSYNC_REQUIRE_ATTESTATION` | `0` | set to `1` to refuse to install unless the provenance check passes |

</TabItem>
<TabItem label="Homebrew">

On macOS or Linux:

```sh
brew install pungoyal/tap/dotsync
```

The formula installs the same release archive as the install script, pinned by its SHA-256 checksum, along with the `dotsync(1)` man page. **Homebrew keeps dotsync up to date**: use `brew upgrade dotsync`. `dotsync update` points you there instead of replacing a file Homebrew owns. The background agent runs `$(brew --prefix)/bin/dotsync`, so an upgrade reaches it too.

</TabItem>
<TabItem label="apt (Ubuntu, Debian)">

Add the signed dotsync repository, then install the package:

```sh
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://pungoyal.github.io/dotsync/apt/dotsync.asc | sudo tee /etc/apt/keyrings/dotsync.asc >/dev/null
curl -fsSL https://pungoyal.github.io/dotsync/apt/dotsync.sources | sudo tee /etc/apt/sources.list.d/dotsync.sources >/dev/null
sudo apt update && sudo apt install dotsync
```

The repository serves the latest release for amd64 and arm64, and the key is only trusted for this repository (`Signed-By`). The package installs `/usr/bin/dotsync` and the man page, and depends on `git`. **apt keeps dotsync up to date** with your other packages (`sudo apt upgrade`); `dotsync update` points you there. Supported on Ubuntu 22.04 and newer, and Debian 12 and newer.

To install without adding the repository, download `dotsync_<version>_<arch>.deb` from the [latest release](https://github.com/pungoyal/dotsync/releases/latest), [verify it](/dotsync/project/verifying-releases/), and run `sudo apt install ./dotsync_*.deb`. You then update by installing the next release's `.deb` the same way.

</TabItem>
<TabItem label="go install">

With Go 1.23 or newer:

```sh
go install github.com/pungoyal/dotsync/cmd/dotsync@latest
```

The binary ends up in `$(go env GOBIN)`, or `~/go/bin` if that's unset.

</TabItem>
<TabItem label="Release binary">

1. Download `dotsync_<version>_<os>_<arch>.tar.gz` from the [latest release](https://github.com/pungoyal/dotsync/releases/latest).
2. Optionally, [verify it](/dotsync/project/verifying-releases/).
3. Extract it and move `dotsync` somewhere on your `PATH`:

   ```sh
   tar -xzf dotsync_*_darwin_arm64.tar.gz dotsync
   install -m 0755 dotsync ~/.local/bin/
   ```

</TabItem>
<TabItem label="From source">

```sh
git clone https://github.com/pungoyal/dotsync
cd dotsync
make build        # → bin/dotsync
```

</TabItem>
</Tabs>

## Put it on your PATH

Homebrew and apt put dotsync on your `PATH` already. With the install script, if `dotsync version` says *command not found*, add `~/.local/bin` to your `PATH`:

<Tabs syncKey="shell">
<TabItem label="zsh">
```sh
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && exec zsh
```
</TabItem>
<TabItem label="bash">
```sh
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc && exec bash
```
</TabItem>
<TabItem label="fish">
```fish
fish_add_path ~/.local/bin
```
</TabItem>
</Tabs>

## Check it works

```console frame="terminal"
$ dotsync version
dotsync 0.1.0 (289c20a, 2026-09-21T06:18:53Z) go1.27.1 darwin/arm64
```

<Aside type="tip">
`dotsync init` also copies the binary to `~/.local/bin/dotsync`, which is where the background agent runs it from. You don't need to install it there yourself. A Homebrew or apt install is used where it is instead, so the package manager's upgrades reach the agent.
</Aside>

## Update

With Homebrew, `brew upgrade dotsync`; with apt, `sudo apt update && sudo apt upgrade`. Otherwise:

```sh
dotsync update           # install the latest release (checksum + provenance verified)
dotsync update --check   # just tell me whether there's a newer one
```

`dotsync doctor` also tells you when an update is available. Both `update` and the install script re-install the background agent with the new version, so there's nothing else to do. Releases before 0.3.0 don't have `update`: run the install script once more to get it.

## Stuck downloading?

The install script shows a progress bar, gives up on a stalled connection after about 20 seconds, and retries, including once over IPv4. If it keeps failing, check your connection to GitHub's download host, which is separate from `github.com`:

```sh
curl -v -o /dev/null https://github.com/pungoyal/dotsync/releases/latest/download/checksums.txt
```

If that also hangs (often an IPv6 route or a proxy), try `curl -4 …` to force IPv4, or download the archive from the [releases page](https://github.com/pungoyal/dotsync/releases/latest) in a browser.
