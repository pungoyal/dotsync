# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be kind, assume good faith, and focus on what's best for the community. Harassment, personal attacks and discriminatory language are not tolerated in any project space: issues, pull requests, discussions, or any other channel.

## Reporting

Report unacceptable behavior privately to the project maintainer, [@pungoyal](https://github.com/pungoyal), by email (address on their GitHub profile). All reports are reviewed promptly and confidentially.

Maintainers may remove, edit or reject contributions that don't follow this code, and may temporarily or permanently ban contributors whose behavior is harmful, as set out in the Covenant's enforcement guidelines.
